# APL_Logistics_Delivery_Analytics
# APL Logistics Delivery Dashboard | Power BI

## Project Overview

This project is an interactive **Power BI dashboard** designed to analyze delivery performance and logistics operations for APL Logistics.

The dashboard focuses on delivery delays, delivery status, shipping mode performance, and regional differences. It brings key performance indicators and interactive visuals together to support operational monitoring and data-driven analysis.

## Project Objectives

* Monitor delivery performance using key metrics.
* Analyze delivery status and delay patterns.
* Compare shipping mode performance.
* Examine regional delivery differences across markets.
* Provide interactive filtering for exploring operational data.

## Tools & Technologies

* **Microsoft Power BI Desktop** – Dashboard development and visualization
* **Power Query** – Data preparation and transformation
* **DAX** – Measures and KPI calculations
* **Power BI visuals and slicers** – Interactive analysis

## Key Performance Indicators (KPIs)

The dashboard includes the following measures:

| KPI                            | Purpose                             |
| ------------------------------ | ----------------------------------- |
| Average Delivery Delay         | Tracks average delivery delay       |
| Late Delivery Risk Ratio       | Indicates late-delivery risk        |
| Shipping Mode Efficiency Index | Compares shipping mode efficiency   |
| Regional Delay Index           | Highlights regional delay patterns  |
| On-Time Delivery Rate          | Tracks on-time delivery performance |

## Dashboard Features

### Delivery Status

A donut chart provides a breakdown of delivery status.

### Shipping Mode Analysis

Visuals compare shipping modes using the Shipping Mode Efficiency Index and scheduled versus actual shipping duration.

### Regional Performance

A bar chart compares the Regional Delay Index across markets.

### Interactive Filters

The dashboard includes slicers for:

* Market
* Shipping Mode
* Customer Segment
* Department Name
* Delivery Status

These filters allow users to explore delivery performance across different operational categories.

## Project Note

This dashboard is intended for analytics and portfolio demonstration. Its metrics and visualizations describe patterns in the available dataset and should not be interpreted as proof of causation.
